## Descrição
A Camera PFE é uma aplicação web desenvolvida para capturar fotografias utilizando a câmera do dispositivo. A aplicação permite identificar cada fotografia com o nome do aluno e a data e hora da captura.

A imagem recebe um filtro sépia e é processada diretamente no navegador, podendo ser visualizada e baixada pelo usuário.

## Recursos utilizados
- HTML5 para a estrutura da página.
- CSS3 para a estilização e responsividade.
- JavaScript para os eventos e a manipulação do DOM.
- MediaDevices e getUserMedia para acessar a câmera.
- Canvas para processar a fotografia.
- context.filter para aplicar o filtro sépia.
- context.fillText() para escrever o nome e a data/hora.
- MediaStream.getTracks() e stop() para desligar a câmera.

## Como executar
1. Clone ou baixe o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Inicie o arquivo index.html usando a extensão Live Server.
4. Autorize o acesso à câmera quando o navegador solicitar.
5. Digite o nome do aluno e capture a fotografia.
